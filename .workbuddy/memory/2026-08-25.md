**踩坑记录：**
- slidep 用 `.slide` 扩展名（SKILL.md 顶层规定的），不是 `.jsx`
- 第一次用 `<Slide>` + 用 `flex: 1` + 大量 padding 导致 overflow → 改用 `height: '固定 px'` 控制 A/B/C 三区
- JSX 字符串字面量 `{'...\n...'}` 不允许跨多行，必须用 `'\n'` escape 成单个字符串
- validator 对 absolute 定位 SVG 不友好，01_cover 改用渐变圆 Box 替代 SVG
- 文件最后一个表达式必须是 `<Slide>`，前面不能 export/import
- `display: 'grid'` 禁用，只允许 `'flex'`；CSS `calc()` 禁用
